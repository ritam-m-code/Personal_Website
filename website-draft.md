## Projects

### 1000 Elo Chessbot
GitHub: https://github.com/j3rry1iu/ChessHacks-Training

A chess engine project built with a ResNet-style CNN, policy and value heads, and depth-3 search to generate moves within 250 ms. The model was trained using Modal cloud compute, with model weights stored and shared through Hugging Face.

Highlights:

- Combined deep learning with search-based decision making
- Built around fast move generation constraints
- Used cloud infrastructure for training and model hosting

### RUL Predictor via Transformer Model
GitHub: https://github.com/ritam-m-code/RUL-Transfomer

A machine learning project focused on predicting the remaining useful life of CNC mill bits from sensor data. The model uses PyTorch to process CSV-based inputs, predict future trends, and visualize outputs with NumPy and Matplotlib.

Highlights:

- Transformer-based time series prediction
- Real-world sensor data pipeline
- Practical industrial manufacturing application

### Recursive Maze Solver
GitHub: https://github.com/ritam-m-code/Maze-Solver

A visual maze generation and solving project built in Processing. The system generates mazes recursively and lets users solve them using Dijkstra's algorithm, DFS, and BFS, with real-time visualization and path optimization features.

Highlights:

- Recursive maze generation
- Multiple pathfinding algorithms
- Visualization-focused interactive design

### Motion Activated Door Monitoring System
GitHub: https://github.com/ryanli222/smartdoorbell

A smart door monitoring system built on a Raspberry Pi using OpenCV, Docker, Ngrok, and FastAPI. When motion is detected, the system activates a display, streams video, plays alerts, supports two-way communication, and uploads images to a backend service.

Highlights:

- Real-time computer vision on edge hardware
- End-to-end system behavior from detection to alerting
- Integrated hardware, backend, and communication flow
