# Personal Portfolio Website

A personal portfolio website built to showcase projects, skills, experience, and contact information in a polished, modern way.

## Goal

Create a portfolio that feels intentional and memorable instead of looking like a generic template. The site should be fast, responsive, and easy to update as new work gets added.

## Planned Stack

- TypeScript for safer, maintainable code
- React for building the UI
- Next.js for routing, performance, and deployment-friendly structure
- Tailwind CSS for styling and rapid iteration
- Framer Motion for tasteful animations
- Vercel for deployment

## Planned Features

- Hero section with a strong introduction
- About section
- Projects showcase with screenshots and links
- Skills and tools section
- Resume download
- Contact section
- Mobile-friendly responsive design
- Smooth page transitions and subtle motion
- Easy-to-edit content structure

## Design Direction

The site should feel modern, creative, and personal. The goal is to avoid a bland portfolio layout and instead build something clean, bold, and memorable with strong typography, motion, and visual hierarchy.

## Project Status

This project is currently in the setup/planning stage.
